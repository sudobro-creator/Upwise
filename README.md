# Upwise Landing Page

Static landing page. No build step.

```
upwise/
├── index.html
├── css/        variables → base → components → sections → responsive
├── js/main.js  tab behaviour
├── assets/     images/ and fonts/ (drop your exported illustrations here)
└── vercel.json
```

Deploy: push to GitHub, import in Vercel, framework preset "Other", leave build settings empty.
